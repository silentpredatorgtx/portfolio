Практические кейсы и примеры работ

🔍 Кейс 1: Локализация бага формы заявки (Bug Report + DevTools)
Manual QA Chrome DevTools Bug Report

Задача: Проверить форму обратной связи и валидацию полей на адаптивной версии сайта.

ID: BUG-104 | Серьезность (Severity): Major | Приоритет: High
Окружение: iOS 17 / Mobile Chrome, разрешение 390×844

Шаги воспроизведения (Steps to Reproduce):
1. Открыть страницу контактов на мобильном устройстве.
2. Ввести корректное имя и номер телефона.
3. Нажать кнопку «Отправить заявку».

Ожидаемый результат: Заявка отправляется (HTTP 200 OK), появляется уведомление об успехе.
Фактический результат: Кнопка зависает в состоянии загрузки. В консоли DevTools (вкладка Network) фиксируется ошибка 400 Bad Request из-за некорректной маски телефона (передаются скобки и пробелы в JSON-запросе).
📋 Кейс 2: Чек-лист кроссбраузерного аудита и верстки
HTML / CSS UI / UX Чек-лист

Задача: Разработка и комплексная проверка веб-страницы перед публикацией.

[✓] Адаптивность (Responsive Design): проверка сетки на 320px, 768px, 1440px (отсутствие горизонтального скролла).
[✓] Интерактивные элементы: проверка состояний кнопок (hover, active) и корректности переходов по внешним ссылкам.
[✓] Безопасность ссылок: использование атрибутов rel="noopener noreferrer" для защиты целевых вкладок.
[✓] Производительность и чистота кода: валидация семантики HTML5, отсутствие ошибок в Console.
🖧 Кейс 3: Развертывание VPS и диагностика сетевой маршрутизации
Linux VPS DNS / Сети L2 Support

Задача: Настройка удаленного виртуального сервера и устранение сбоев сетевого соединения.

• Администрирование: Подключение к Linux-серверу по SSH, базовая настройка фаервола и сетевых интерфейсов.
• Маршрутизация и DNS: Настройка защищенного DNS (DoH), проверка прохождения пакетов, анализ задержек (ping / traceroute) и разрешение конфликтов портов.
• Результат: Обеспечена бесперебойная связь клиентских устройств (Windows / iOS) с сервером и составлена пошаговая инструкция по подключению.
